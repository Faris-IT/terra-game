# Mufa Terra
Small Actions. A Living World. (Game #6 Mufa Games)

Game simulasi lingkungan 3D low-poly prosedural: jelajahi Kampung Arunika, pilah sampah, olah material, buat produk, dan pulihkan lingkungan.
HTML, CSS, Vanilla JavaScript, Three.js r128 (CDN). Tanpa model, tekstur, gambar, atau audio eksternal.

## Menjalankan
Buka `index.html` di browser (perlu internet saat pertama memuat Three.js dari CDN).

## Deploy ke GitHub Pages
1. Upload seluruh isi folder ke repository.
2. Settings → Pages → pilih branch `main`, folder `/ (root)`.
3. Buka URL Pages yang diberikan.

## Kontrol
WASD gerak · Shift lari · seret mouse kamera · scroll jarak · E interaksi · I inventaris · J misi · B buku · Esc menu/pengaturan.
Mobile: joystick virtual, tombol E, Tas, Menu, Misi, Buku.

## Fitur
- Phase 1: karakter prosedural, kamera third-person, sampah, inventaris, pemilahan.
- Phase 2: kualitas dan kontaminasi, fasilitas, resep dan crafting, distribusi, Coins/XP/Trust, save/load.
- Phase 3: Pasar Lestari, Sungai Nirmala, 3 NPC, dialog, 5 misi, perubahan visual lingkungan.
- Phase 4: upgrade, achievement, tantangan harian/mingguan, pesanan komunitas, Collection Book, rekor, Eco Score.
- Phase 5: tutorial 6 langkah, pengaturan grafis dan aksesibilitas, audio Web Audio, grafis adaptif, uji sistem.

## Catatan
- Angka produksi dan harga adalah balancing game, bukan standar industri atau harga pasar.
- Warna air adalah indikator ilustratif, bukan pengukuran kualitas air.
- Validasi materi edukasi dengan sumber tepercaya (lihat bagian referensi di dokumen desain) sebelum rilis publik.
- Fitur online (leaderboard, multiplayer, akun) belum ada.
