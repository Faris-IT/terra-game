# Mufa Terra — Phase 4 (Progression and Competition)
Small Actions. A Living World. (Game #6 Mufa Games)

HTML, CSS, Vanilla JavaScript, Three.js r128 (CDN). Tanpa aset eksternal.

## Menjalankan
Buka `index.html` (perlu internet untuk memuat Three.js dari CDN) atau upload ke GitHub Pages.

## Kontrol
WASD gerak · Shift lari · seret mouse kamera · scroll jarak · E interaksi · I inventaris · Esc menu · J misi · B buku. Mobile: joystick + tombol E/Tas/Menu.
