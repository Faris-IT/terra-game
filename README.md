# Mufa Terra — Phase 2 (Core Gameplay)
Small Actions. A Living World. (Game #6 Mufa Games)

HTML, CSS, Vanilla JavaScript, Three.js r128 (CDN). Tanpa aset eksternal.

## Menjalankan
Buka `index.html` (perlu internet untuk memuat Three.js dari CDN) atau upload ke GitHub Pages.

## Kontrol
WASD gerak · Shift lari · seret mouse kamera · scroll jarak · E interaksi · I inventaris · Esc menu. Mobile: joystick + tombol E/Tas/Menu.

## Status
- Phase 1: karakter prosedural, kamera, sampah, inventaris, pemilahan.
- Phase 2: kualitas & kontaminasi, pembersihan, Compost Center, Workshop Kertas & Kreatif, resep & crafting, Gudang Distribusi, Coins/XP/Trust, save/load (schema v2 + backup).
- Berikutnya Phase 3: Kampung Arunika lengkap, Pasar Lestari, Sungai Nirmala, NPC, dialog, misi, perubahan visual.
