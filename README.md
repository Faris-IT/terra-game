# Mufa Terra — Phase 1 Prototype
Small Actions. A Living World. (Game #6 Mufa Games)

Simulasi lingkungan 3D low-poly prosedural (HTML, CSS, Vanilla JavaScript, Three.js r128 via CDN). Tanpa model, tekstur, gambar, atau audio eksternal.

## Menjalankan
Buka `index.html` di browser (perlu internet saat pertama memuat Three.js dari CDN), atau upload ke GitHub Pages.

## Kontrol
WASD gerak · Shift lari · seret mouse untuk kamera · scroll untuk jarak · E interaksi · I inventaris. Mobile: joystick virtual + tombol E/Tas.

## Status
Phase 1 selesai: karakter prosedural, kamera third-person, 7 jenis sampah, inventaris, pemilahan 4 kategori.
Berikutnya Phase 2: kualitas/kontaminasi, fasilitas, resep, crafting, distribusi, Coins, save/load.
